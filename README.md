# 🍯 HoneyNode-AI

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://honeynode-ai.streamlit.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An **Autonomous Deception & Threat Capture Engine** engineered for real-time honeypot telemetry profiling and MITRE ATT&CK mapping.

## 🌟 Key Capabilities
* **Attacker Profiling:** Classifies automated bots vs. targeted interactive human recon.
* **Payload & Command Analysis:** Decodes adversary commands, malware drops, and lateral movement attempts.
* **TTP Mapping:** Maps observed actions to MITRE ATT&CK framework tactics and techniques.

Developed as part of the **Sovereign AI Stack (SAS)** research initiative at **IHFC — IIT Delhi**.
